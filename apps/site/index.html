작동 방식How it works

  1. 검사Scan

    읽기만 합니다. 파일을 열거나 바꾸지 않고, 클라우드에만 있는 파일을 내려받지 않습니다.Read-only. Lumen never opens or changes files, and never downloads files kept only in the cloud.

  2. 판단Decide

    정해진 안전 규칙이 항목마다 유지, 검토 필요, 정리 제안 중 하나로 판단하고 이유를 보여 줍니다.A fixed safety policy marks each item Keep, Review or Proposed, and shows why.

  3. 확인Confirm

    정리 제안된 항목을 보고 직접 확인합니다. 확인하기 전에는 아무것도 옮기지 않습니다.You review the proposed items and confirm. Nothing moves before you do.

  4. 격리Quarantine

    확인한 항목은 지우지 않고 격리함으로 옮깁니다. 영구 삭제하기 전까지 복원할 수 있고, 영구 삭제는 요청할 때만 합니다. 공간은 그때 비워집니다.Confirmed items move to Quarantine instead of being deleted. You can restore them until you remove them for good, which happens only when you ask. That is when the space is freed.

확실하지 않으면 그대로 둡니다When in doubt, Lumen leaves it alone

  • 시스템 파일, 문서, 자격 증명과 키, 브라우저 프로필, 데이터베이스는 정리를 제안하지 않습니다.System files, documents, credentials and keys, browser profiles and databases are never proposed.
  • 읽지 못한 폴더는 비어 있는 것으로 보지 않습니다. 그 안의 항목은 그대로 둡니다.A folder Lumen cannot read is not treated as empty. Nothing in it is proposed.
  • 사용 중인 파일과 클라우드와 동기화된 파일은 건드리지 않습니다.Files in use and files synced with a cloud service are left alone.
  • 옮기기 직전에 항목마다 다시 확인하고, 복원할 때 아무것도 덮어쓰지 않습니다.Every item is checked again just before it moves, and restoring never overwrites anything.

개인정보Privacy

검사 결과, 판단, 격리함, 기록은 이 컴퓨터에만 있습니다. 사용 통계, 오류 보고, 추적은 없습니다.Scan results, decisions, Quarantine and logs stay on this computer. No usage statistics, crash reports or tracking.

AI 검토(선택).AI review (optional). 기본으로 꺼져 있고, 설정에서 직접 켜야 합니다. 켜면 정리 제안된 항목의 메타데이터(경로, 크기, 경과 기간, 판단 근거. 홈 폴더는 ~로 표시)만 학교의 Jeb 서버로 보냅니다. 파일 내용은 보내지 않습니다. AI는 판단을 더 신중하게만 바꿀 수 있고, 무엇을 옮길지 고를 수 없습니다. 서버 운영자가 요청을 보관할 수 있습니다.Off by default; you turn it on in Settings. Then only metadata about proposed items (path, sizes, ages and evidence, with your home folder shown as ~) goes to the school's Jeb server. File contents are never sent. AI can only make a decision more cautious; it cannot choose what is moved. The server's operator may keep the requests.

처음 열기Opening Lumen the first time

아직 코드 서명이 없어서 macOS와 Windows가 처음 실행을 막습니다. 한 번만 허용하면 됩니다.Lumen is not code-signed yet, so macOS and Windows block its first launch. You only need to allow it once.

macOS
  1. .dmg를 열고 Lumen을 응용 프로그램 폴더로 끌어 놓습니다.Open the .dmg and drag Lumen into Applications.
  2. Lumen을 엽니다. 열 수 없다는 창이 나오면 완료를 누릅니다.Open Lumen. When macOS says it cannot be opened, click Done.
  3. 시스템 설정 › 개인정보 보호 및 보안에서 아래 보안 부분의 “그래도 열기”를 누르고 암호나 Touch ID로 확인합니다.In System Settings › Privacy & Security, scroll to Security, click “Open Anyway” and confirm with your password or Touch ID.
  4. Lumen을 다시 열고 그래도 열기를 누릅니다. 다음부터는 그냥 열립니다.Open Lumen again and click Open Anyway. After that it opens normally.

macOS 15부터는 Control-클릭으로 열기가 통하지 않습니다. macOS 13, 14에서는 Control-클릭 › 열기도 됩니다.From macOS 15, Control-click no longer bypasses the block. On macOS 13 and 14, Control-click › Open also works.

macOS 전체 디스크 접근 권한macOS Full Disk Access

허용하지 않으면 메일, 메시지, 다른 앱의 데이터 같은 보호된 폴더는 ‘읽지 못함’으로 남고 정리를 제안하지 않습니다.Without it, protected folders such as Mail, Messages and other apps' data stay unreadable and nothing in them is proposed.

  1. 시스템 설정 › 개인정보 보호 및 보안 › 전체 디스크 접근 권한을 엽니다. Lumen 설정의 버튼으로도 열 수 있습니다.Open System Settings › Privacy & Security › Full Disk Access, or use the button in Lumen's Settings.
  2. Lumen을 켭니다. 목록에 없으면 +로 응용 프로그램 폴더의 Lumen을 추가합니다.Turn Lumen on. If it is not listed, add it from Applications with +.
  3. Lumen을 종료했다가 다시 열고 다시 검사합니다.Quit and reopen Lumen, then scan again.

서명이 없어서 업데이트한 Lumen을 macOS가 다른 앱으로 볼 수 있습니다. 업데이트 뒤 폴더를 읽지 못하면 목록에서 Lumen을 −로 지우고 다시 추가하세요.Without a signature, macOS may see an updated Lumen as a different app. If folders are unreadable after an update, remove Lumen from the list with − and add it again.

Windows
  1. 브라우저가 다운로드를 경고하면 다운로드 목록의 메뉴에서 유지를 고릅니다.If your browser warns about the download, choose Keep in the download's menu.
  2. 설치 프로그램을 실행합니다. Windows의 PC 보호 창에서 추가 정보를 누른 다음 실행을 누릅니다.Run the installer. In Windows protected your PC, click More info, then Run anyway.
  3. 시작 메뉴에서 Lumen을 엽니다. 관리자 권한으로 실행하면 Lumen은 파일을 옮기지 않습니다.Open Lumen from the Start menu. Run as administrator, Lumen will not move files.

자주 묻는 질문FAQ

왜 경고가 나오나요?Why the warning?

Lumen이 아직 Apple(Developer ID, 공증)과 Microsoft의 코드 서명을 받지 않았기 때문입니다. 운영 체제가 개발자를 확인할 수 없다는 뜻이지, 악성 코드를 찾았다는 뜻은 아닙니다. 서명은 계정이 준비되면 추가합니다. 그때까지는 체크섬과 빌드 증명으로 파일을 확인할 수 있습니다.Lumen is not code-signed by Apple (Developer ID, notarization) or Microsoft yet. The warning means your system cannot identify the developer; it does not mean malware was found. Signing comes once the accounts exist. Until then you can check files with checksums and build provenance.

써도 안전한가요?Is it safe?

베타라서 버그가 있을 수 있습니다. 그래서 보수적으로 동작합니다. 확실하지 않으면 그대로 두고, 정리는 확인한 항목을 격리함으로 옮기는 것뿐이며, 영구 삭제 전까지 복원할 수 있습니다. 소스 코드는 공개되어 있고 릴리스는 GitHub Actions에서 그 코드로 빌드됩니다. 중요한 데이터는 따로 백업해 두세요.It is a beta, so it may have bugs. That is why it is cautious: when unsure it leaves things alone, cleaning up only moves confirmed items into Quarantine, and you can restore them until you remove them for good. The source is public and releases are built from it on GitHub Actions. Keep a backup of anything important.

AI 검토는 무엇을 보내나요?What does AI review send?

켜기 전에는 아무것도 보내지 않습니다. 켜면 정리 제안된 항목마다 경로(홈 폴더는 ~), 크기, 경과 기간, 판단 근거만 학교의 Jeb 서버로 보냅니다. 학교 AI Hub에서 발급한 키가 필요합니다. AI의 답은 판단을 더 신중하게만 바꿀 수 있고, 답이 없거나 형식이 맞지 않으면 무시됩니다. 켜면 끌 때까지 유지되며, 설정에서 언제든 끌 수 있습니다.Nothing until you turn it on. Then, for each proposed item, only the path (home folder shown as ~), sizes, ages and evidence go to the school's Jeb server. It needs a key from the school's AI Hub. Its answer can only make a decision more cautious, and a missing or malformed answer is ignored. It stays on until you turn it off in Settings.

정리한 항목은 어떻게 되돌리나요?How do I get something back?

격리함에서 항목을 고르고 복원을 누르세요. 원래 자리에 원래 이름으로 돌아갑니다. 그 자리에 같은 이름의 항목이 생겼다면 덮어쓰지 않고 격리함에 남겨 둡니다.In Quarantine, select the item and choose Restore. It returns to its original place and name. If something else now has that name, nothing is overwritten and the item stays in Quarantine.

어떻게 제거하나요?How do I uninstall it?

먼저 격리함의 항목을 복원하거나 영구 삭제하세요. 앱을 지워도 격리함은 남아 공간을 차지합니다.First restore or permanently remove what is in Quarantine. Uninstalling leaves Quarantine in place, still using space.

  • macOS: 응용 프로그램 폴더의 Lumen을 휴지통으로 옮깁니다. 데이터는 ~/Library/Application Support/dev.lumen.desktop, 격리함은 ~/Library/Application Support/Lumen/Quarantine에 있습니다.macOS: move Lumen from Applications to the Trash. Its data is in ~/Library/Application Support/dev.lumen.desktop, Quarantine in ~/Library/Application Support/Lumen/Quarantine.
  • Windows: 설정 › 앱 › 설치된 앱에서 제거합니다. 격리함은 %LOCALAPPDATA%\Lumen\Quarantine에 있습니다.Windows: uninstall in Settings › Apps › Installed apps. Quarantine is in %LOCALAPPDATA%\Lumen\Quarantine.
  • Linux: sudo apt remove lumen 또는 AppImage 파일 삭제. 격리함은 ~/.local/share/lumen/quarantine에 있습니다.Linux: sudo apt remove lumen, or delete the AppImage. Quarantine is in ~/.local/share/lumen/quarantine.
업데이트는 어떻게 하나요?How do I update?

자동 업데이트는 아직 없습니다. 새 버전을 이 페이지에서 내려받아 같은 방법으로 설치하세요. 업데이트 뒤 그래도 열기와 전체 디스크 접근 권한을 다시 해야 할 수 있습니다.There are no automatic updates yet. Download the new version here and install it the same way. You may need to choose Open Anyway and grant Full Disk Access again afterwards.

베타에서 아직 안 되는 것은?What is missing in the beta?

0.x 동안은 기능과 화면이 바뀔 수 있고, 서명과 자동 업데이트가 없습니다. 지금은 사용자 폴더가 있는 디스크의 항목만 격리할 수 있고, 다른 디스크의 항목은 그대로 둡니다. 휴대폰 앱은 아직 없습니다. 문제는 GitHub 이슈로, 보안 문제는 보안 정책에 따라 알려 주세요.During 0.x, features and screens may change, and there is no signing or automatic update. Only items on the disk with your user folder can be quarantined; items on other disks stay where they are. There is no phone app yet. Report problems as GitHub issues, and security issues as described in the security policy.
